
Это утилита резервного копирования и обслуживания баз данных 1С.
Её основная задача - выгрузка ИБ 1С в *.dt
Два режима работы: непосредственно в момент запуска и по расписанию через планировщик.
Утилита кросс платформенная и может работать с файловыми (в том числе сетевыми), PostgreSQL и MSSQL базами.
При этом одновременно только с файловыми и какой-то одной СУБД.

Удаление старых копий перед созданием новых
