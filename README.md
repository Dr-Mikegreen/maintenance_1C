Это еще не релиз! Пока это черновик и большая часть функционала не реализована.

Это утилита резервного копирования и обслуживания баз данных 1С.
Её основная задача - регулярная выгрузка ИБ в *.dt по расписанию.
Есть вохможность включить проверкм копий на валидность и неторые методы обслуживания средствами СУБД.
Обслуживание средствами СУБД вторично и не в полной мере.
Утилита кросс платформенная и может работать с файловыми, PostgreSQL и MSSQL базами.
При этом одновременно только с файловыми и какой-то одной СУБД.

Не забываем ограничивать права на конфиг с паролями

PostgreSQL:
  STATISTICS → ANALYZE
  INDEXES    → REINDEX
  INTEGRITY  → VACUUM / VACUUM FULL

MSSQL:
  STATISTICS → UPDATE STATISTICS
  INDEXES    → REORGANIZE / REBUILD
  INTEGRITY  → DBCC CHECKDB
