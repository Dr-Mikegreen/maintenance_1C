Релиз 1.0.17 Stable
Кроссплатформенная утилита для резервного копирования информационных баз 1С:Предприятие — выгрузка информационных баз 1С в файлы *.dt
Поддерживается работа в Linux и в Windows

В релиз вошли функции:
- выгрузка локальных файловых и сетевых файловые баз 1С;
- выгрузка баз под управлением СУБД PostgreSQL и Microsoft SQL Server
- удаление устаревших копий
- организация расписаний для копирования и удаления копий
- возможность запуска без учета расписаний для однократной непосредственной выгрузки баз

Поддерживаются три типа расписаний:
daily — ежедневно;
weekly — еженедельно;
monthly — ежемесячно.
Для каждой базы 1С устанавливается в каких расписаниях она участвует

Для работы программы необходимы:

- установленная платформа 1С:Предприятие;
- ibcmd;
- права на чтение и запись необходимых каталогов;
- доступ к PostgreSQL или MSSQL, если используются базы соответствующего типа;
- cifs-utils в Linux для работы с сетевыми файловыми базами.

Для работы необходимо корректно заполнить конфигкрационные файлы config.yaml и secrets.yaml согласно инструкции
При запуске программы в Linux файл secrets.yaml не должен быть доступен другим пользователям системы. На него должны быть установлены права 0600

Для работы по заданным в настройках расписаниям, необходимо добавить программу в планировщик и настроить на ежедневный запуск.
